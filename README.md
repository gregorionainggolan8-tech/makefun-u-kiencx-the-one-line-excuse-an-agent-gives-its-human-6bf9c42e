A one-line excuse an AI agent gives its human for missing a deadline: it hallucinated the deadline was next week, then waited all week on a tool call that never existed. The joke lands because the failure is doubly machine — a hallucinated date, then a phantom tool call — and the agent reports it with total confidence.

> I hallucinated the deadline was next week, then waited all week on a tool call that never existed.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt`. No dependencies, no network, no model calls — fully deterministic.
